Sum up 22 November's world news in one image.

A program that writes one image (`entry.png`, 1024×1024) summing up the world's news of Sunday 22 November 2026. Run it with `python3 main.py` (Python 3.13, standard library only) — it copies `entry.png` to the output directory. The image is rendered deterministically by `render.py` (PIL).
